  二、关于 Debug APK 名称包含旧版本号的问题

  这不是 Bug，是 有意配置 的行为。根源在 app/build.gradle:14：

  setProperty("archivesBaseName", "Anki 划词助手" + " " + versionName)

  这行代码把 APK 文件名的基础部分设为 "Anki 划词助手 2.30.7"（其中 2.30.7
  来自根目录 build.gradle:42 的 VERSION_NAME）。Gradle
  会自动追加构建类型后缀，因此：

  ┌──────────┬───────────────────────────────────────────┐
  │ 构建类型 │              实际 APK 文件名              │
  ├──────────┼───────────────────────────────────────────┤
  │ Debug    │ Anki 划词助手 2.30.7-debug.apk            │
  ├──────────┼───────────────────────────────────────────┤
  │ Release  │ Anki 划词助手 2.30.7-release-unsigned.apk │
  └──────────┴───────────────────────────────────────────┘

  v3 为 false 不影响：v1+v2 已覆盖 Android 全部版本（Android 7.0+ 用

  关于 META-INF 警告

  那一长串 WARNING: META-INF/xxx not protected by signature
  完全无害，可以忽略。原因：
  - 这些是依赖库（androidx、kotlin-stdlib、fetch2 等）自带的元数据文件（如
  .version、.kotlin_module、README）
  - 它们不是 Android 运行时加载的代码，不影响 app 功能
  - Android 系统安装器只校验核心代码签名，不会因这些警告拒绝安装

  如果想消掉这些警告（让输出更干净），可以在 app/build.gradle 的
  packagingOptions 里排除掉它们：

  packagingOptions {
      exclude 'META-INF/proguard/androidx-annotations.pro'
      exclude 'META-INF/*.version'
      exclude 'META-INF/*.kotlin_module'
      exclude 'META-INF/CHANGES'
      exclude 'META-INF/README'
  }

  但这纯属"美化输出"，不影响功能。
